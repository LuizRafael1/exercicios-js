# Exercícios JS

Repositorio com exercícios de JavaScript que venho fazendo por conta própria, 
como forma de praticar a lógica de programação e fixar conceitos da linguagem. 

🔨 Novos exercícios serão adicionados conforme avanço nos estudos.

## Objetivo

- Praticar lógica de programação
- Fixar conceitos fundamentais de JavaScript
- Manter a constância nos estudos com exercícios curtos e frequentes

## Organização

Cada arquivo representa um exercício, nomeado de forma sequencial, 
por exemplo:

- `exercicio-1.js`
- `exercicio-2.js`
- `exercicio-3.js`
